# 量測與匯出格式

Switchback 不修補軌跡、不預測速度，也不補入沒有記錄的高度或時間。GPX 的每個 `trkseg` 都視為獨立的連續記錄；即使兩段的座標接近，也不連接區段。

## 距離與高度

距離對同區段中每對相鄰座標套用半正矢公式，使用半徑 6,371,008.8 公尺的球體近似地球。這不是橢球測地線的高精度解，也不是加計高度的三維路程。經度跨越 ±180° 時，距離採球面最短弧。

爬升是正高度差之和，下降是負高度差絕對值之和。缺少任一端高度時，該對不參與計算；沒有任何可用相鄰對時，結果是未知，不是零。最低／最高點則使用選取範圍內所有已知高度，即使只有一點也可顯示。沒有平滑處理，定位與高度雜訊可能增加爬升和下降。

「可用相鄰點」的分母為範圍內、同一區段內的相鄰點對數。跨區段與不連續索引不計入。分子是同時有有效高度或嚴格遞增時間的點對數；部分資料的加總不能當成完整行程總量。

## 時間

已記錄時間是同一區段中，每對相鄰且時間嚴格遞增的毫秒差加總。重複、倒退及缺漏的時間不計入。停留期間仍可能有遞增時間，因此這不是移動時間。沒有推估速度或暫停偵測。

時間欄位要求有效的 ISO 日期、時間與時區，例如 `2026-04-12T07:30:00Z` 或 `2026-04-12T15:30:00+08:00`。匯出與查看時一律正規化為 UTC。不支援閏秒 `:60`。日期不存在、沒有時區或超出範圍會拒絕整份檔案。

## 圖表與匯入

路線使用以平均緯度調整比例的等距圓柱投影；跨日界線時解開經度。多個區段共享座標框架，但極大跨度、繞行全球或極區路線可能無法直觀呈現。沒有背景地圖、地形或導航資訊。圖表抽樣約 1,200 點，另保留路線區段端點；高度缺值與區段缺口不會被畫成連續線。滑桿能查看每個原始點，量測與匯出也使用所有點。

支援 GPX 1.0、1.1 的正確命名空間（含前綴），以及無命名空間的常見軌跡匯出。只讀取直接位於 `trk / trkseg / trkpt` 結構的資料；擴充欄位不會冒充軌跡點。`rte` 路線規劃、`wpt` 航點不在支援範圍。

檔案上限 10 MiB、100,000 點、1,000 個非空區段；緯度 ±90°、經度 ±180°、高度 ±1,000,000 公尺。空區段忽略。錯誤 XML、DTD／實體宣告、缺漏或錯誤座標，以及有填寫卻無效的高度或時間，會拒絕整份新檔，保留先前顯示內容。重疊匯入以最後開始讀取的操作為準；回到示範軌跡會取消尚未完成的匯入。

## JSON

`schemaVersion` 目前為 `1`。JSON 使用固定英文機器欄位，與介面語言無關。

| 欄位 | 意義 |
| --- | --- |
| `name` | 來源檔案的軌跡名稱 |
| `units` | 距離、高度為公尺；時間差為毫秒；座標為度 |
| `selection.firstPoint / lastPoint` | 選取的原始點號，從 1 開始，包含兩端 |
| `summary.distance` | 選取範圍內的水平距離 |
| `summary.ascent / descent` | 可計算的原始爬升／下降；無可用點對時為 `null` |
| `summary.totalPairs` | 同區段內的相鄰點對數 |
| `summary.elevationPairs / timedPairs` | 有效高度／時間點對數 |
| `summary.elapsed` | 已記錄時間；無可用時間點對時為 `null` |
| `summary.nonIncreasingTimes` | 被排除的相同或倒退時間點對數 |
| `summary.minElevation / maxElevation` | 已知最低／最高高度；沒有高度時為 `null` |
| `points[].lat / lon` | 原始 WGS84 緯度／經度 |
| `points[].elevation` | 原始高度；缺漏為 `null` |
| `points[].time` | UTC ISO 時間字串；缺漏為 `null` |
| `points[].distance` | 自**原始軌跡起點**的累積距離；選取範圍匯出不歸零 |
| `points[].index / segment` | 原始點索引／非空區段索引，從 0 開始 |
| `methods` | 匯出時附上的固定英文計算規則，便於資料處理程式辨認 |

選取範圍的第一個點仍保留它在原始軌跡中的累積距離，但 `summary.distance` 只計算範圍內距離。即使介面切換成英制，JSON 與 CSV 仍輸出公制原始資料。

## CSV

UTF-8，下載時附 BOM，逗號分欄、CRLF 換行。缺漏值使用空白儲存格，不以 `0` 代替。文字經雙引號跳脫；可能被試算表當成公式的文字加上單引號前綴。座標與高度維持數字型態，負值不會改成文字。

| 欄位 | 意義 |
| --- | --- |
| `point` | 原始點號，從 1 開始 |
| `segment` | 非空區段號，從 1 開始 |
| `latitude_deg / longitude_deg` | WGS84 座標，單位為度 |
| `elevation_m` | 原始高度，公尺 |
| `time_utc` | UTC ISO 時間字串 |
| `cumulative_track_distance_m` | 自原始軌跡起點的水平累積距離，公尺 |

CSV 不包含使用者提供的軌跡名稱，避免試算表公式與不必要的中繼資料；JSON 的名稱保持普通字串，不會作為 HTML 執行。

規格依據：[GPX 1.1 結構與欄位](https://www.topografix.com/GPX/1/1/)；[瀏覽器 File API](https://developer.mozilla.org/en-US/docs/Web/API/File_API)。
