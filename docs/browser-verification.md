# 瀏覽器驗證紀錄

2026-10-08，以桌面 Chromium 實際操作開發版；正式網址在發佈後另行檢查。這份紀錄描述已執行的範圍，不等同完整的跨瀏覽器或輔助科技認證。

## 實際操作

- 預設繁體中文，切換英文後保留目前軌跡點；切回繁中仍可操作。
- 使用滑鼠連續拖曳軌跡點滑桿，再按方向鍵移動一點，焦點與連動顯示維持正確。
- 匯入自行建立的兩區段 GPX：4 個點，兩段中間有約一度經緯度的缺口。介面與下載的 JSON 都得到距離 **222.39016046733764 m**、爬升 **20 m**、已記錄時間 **120,000 ms**，沒有加入區段間缺口。
- 實際下載 CSV 並以標準 CSV reader 讀回：4 列、座標及累積距離符合原始軌跡，UTF-8 BOM 可正確移除。
- 匯入缺少中間點海拔、沒有時間的檔案：爬升、下降、時間顯示未知，且顯示 **0 / 2** 組可用相鄰點。
- 匯入破損 XML：顯示繁體中文錯誤，原先有效軌跡維持不變。
- 390 × 844 px 手機寬度及 1440 px 桌面配置：頁面沒有水平溢出。操作截圖取自實際頁面。
- 上述操作後的瀏覽器 console 未出現應用程式錯誤。
